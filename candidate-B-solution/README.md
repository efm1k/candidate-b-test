# Отчёт по авансам и работам подрядчиков

Скрипт читает выгрузку из `data/` и на указанную дату считает по каждой работе: цена, сколько уже выплачено, сколько осталось. По договору — итог, нераспределённый аванс и переплату.

Деньги считаются в `decimal.Decimal`, без `float`. Сторонние библиотеки не нужны.

## Как запустить

Нужен Python 3.9 или новее. Из этой папки:

```
python report.py 10.11.2026
```

Дата также принимается в ISO:

```
python report.py 2026-11-10
```

Другая папка с CSV:

```
python report.py 10.11.2026 --data-dir data
```

Кодировка вывода — UTF-8. На Windows, если в консоли кракозябры, можно так:

```
python report.py 10.11.2026 > report-10-11-2026.txt
```

и открыть файл в редакторе.

## Тесты

```
python -m unittest test_report -v
```

Проверяются авансы, прямые платежи, возвраты, очередь, отмены, исторические даты, переплата, инварианты «деньги не теряются» и контрольная дата 10.11.2026.

## Что смотреть в отчёте

- **Выплачено** — деньги, которые на дату уже ушли подрядчику и не вернулись.
- **Остаток** по работе — сколько ещё нужно, чтобы закрыть обязательство этой работы. У отменённой работы остаток 0.
- **Из них напрямую / из аванса** — платёж с `work_id` и доля договора без привязки.
- **Нераспределённый остаток** — аванс, который ещё не закрыл ни одну принятую работу.
- **К оплате по договору (нетто)** — сумма остатков по работам минус нераспределённый аванс.
- Платежи в очереди показаны, но **не входят** в выплаченное.

Подробности и спорные места — в `DECISIONS.md`. Короткая записка для бухгалтера — в `ACCOUNTANT_NOTE.md`.

Исходные CSV не менялись.
